# Technology Trends Data Analysis

## 📌 Project Overview

This project analyzes **Stack Overflow Developer Survey data** to identify developer demographics, current technology usage, and future technology preferences.

The project explores the technologies developers currently work with and the technologies they would like to work with in the future. The findings are presented through data analysis, visualizations, dashboards, and a final presentation.

This project was completed as part of the **IBM Data Analyst Professional Certificate on Coursera**.

---

## 🎯 Project Objectives

The main objectives of this project were to:

* Analyze the demographic characteristics of survey respondents.
* Examine current programming language usage.
* Analyze current database usage.
* Examine current platform and web framework usage.
* Identify programming languages developers want to work with in the future.
* Identify databases developers want to work with in the future.
* Identify platforms and web frameworks developers want to work with in the future.
* Use data visualizations and dashboards to communicate the findings.
* Identify technology trends that may be relevant to developers, employers, and the technology job market.

---

## 📊 Dataset

The project uses data from the **Stack Overflow Developer Survey**.

The original dataset used during the project was larger than the file-size limit for direct GitHub upload. Therefore, this repository contains a **5,000-row sample dataset** containing the main variables used for the analysis.

The sample includes variables related to:

* Age
* Country
* Formal education
* Years of professional coding experience
* Programming languages currently used
* Programming languages developers want to use
* Databases currently used
* Databases developers want to use
* Platforms currently used
* Platforms developers want to use
* Web frameworks developers want to use

### Dataset note

The GitHub notebook uses the sample dataset for demonstration and reproducibility. Results from the sample may differ from results obtained using the complete original dataset.
