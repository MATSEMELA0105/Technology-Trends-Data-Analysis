# Technology Trends Data Analysis

## 📌 Project Overview

This project analyzes **Stack Overflow Developer Survey data** and job market information to identify current and emerging technology trends in the technology industry.

The analysis focuses on **developer demographics, current technology usage, and future technology preferences**. The results are presented through data visualizations and interactive dashboards to provide insights into technologies that are currently popular and those developers expect to work with in the future.

This project was completed as part of my **IBM Data Analyst Professional Certificate on Coursera**.

---

## 🎯 Project Objectives

The main objectives of this project were to:

* Analyze the demographics of developers.
* Identify the technologies developers currently use.
* Identify technologies developers want to work with in the future.
* Compare current technology usage with future technology preferences.
* Identify technology trends that may be important to the job market.
* Present findings using clear and effective data visualizations and dashboards.

---

## 📊 Dataset

The primary dataset used in this project is the **Stack Overflow Developer Survey**.

The dataset contains information about developers, including:

* Age
* Country
* Formal education
* Programming languages
* Databases
* Platforms
* Web frameworks
* Years of professional coding experience
* Technologies developers currently use
* Technologies developers want to work with in the future

Additional job market data was used to provide context around technology demand.

## 📈 Analysis & Dashboards

### 1. Demographics Dashboard

The demographics analysis examines the characteristics of survey respondents.

Key areas analyzed include:

* Respondent distribution by age
* Respondent count by country
* Formal education levels
* Age distribution by education level

### 2. Current Technology Usage Dashboard

This dashboard identifies the technologies developers currently use.

The analysis includes the top technologies for:

* Programming languages
* Databases
* Platforms
* Web frameworks

### 3. Future Technology Trends Dashboard

This dashboard examines the technologies developers would like to work with in the future.

The analysis focuses on:

* Top programming languages developers want to use
* Top databases developers want to use
* Top platforms developers want to use
* Top web frameworks developers want to use
